# Напоминатель — учебный ИИ-агент в MAX

Проблема: увидел сообщение в чате, подумал «важно, вернусь», вернулся к работе — забыл.
Решение: пересылаешь сообщение боту (или пишешь заметку), он извлекает задачу и срок,
а раз в день присылает список с галочками. Неотмеченное возвращается, пока не посмотришь.

## Запуск

1. Создайте бота на [платформе MAX для партнёров](https://dev.max.ru/docs/chatbots/bots-create/create) или в мини-приложении «MAX для бизнеса»: раздел «Чат-боты» → «Создать». После модерации (до 48 часов по рабочим дням) скопируйте токен бота.
2. `copy .env.example .env` и заполните `MAX_BOT_TOKEN`, `folder_id`, `api_key`.
3. `pip install -r requirements.txt`
4. `python -m bot.main`

Без MAX, в консоли: `python -m bot.main --console`.

## Что умеет

- Переслать сообщение или написать заметку → бот сохраняет дело и срок («до пятницы» считается от сегодняшней даты).
- «Что у меня в списке?» → список открытых дел.
- «Согласия собрал» → бот находит пункт и отмечает его.
- `/digest` или каждый день в `DIGEST_HOUR` → список с кнопками-галочками; нажатие редактирует то же сообщение.

## Куда развивать

- Напоминание в чат родителям или ученикам — отдельный инструмент `send_to_chat`, который исполняется только после подтверждения учителя кнопкой.
- Голосовые заметки → распознавание речи → тот же `run_agent`.
- Приоритеты и группировка дайджеста моделью (сейчас дайджест детерминированный).
